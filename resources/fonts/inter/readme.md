# Inter report fonts

Inter is the application's interface font. These static Regular (400) and Bold (700) TrueType files are embedded locally in report PDFs so generation does not depend on remote font requests.

Source: [Google Fonts Inter stylesheet](https://fonts.googleapis.com/css?family=Inter:400,700), downloaded November 11, 2026. The files are distributed under the SIL Open Font License in [OFL.txt](OFL.txt).
